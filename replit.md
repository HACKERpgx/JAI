# JAI - Just Artificial Intelligence

## Overview
A stunning, premium website homepage for JAI (Just Artificial Intelligence), heavily inspired by xAI's Grok website aesthetic. Features dark mode design, animated gradients, and Apple-level polish with mobile-first responsiveness.

## Project Type
Static landing page / marketing site

## Tech Stack
- **Frontend**: React, TypeScript, Tailwind CSS, Framer Motion, Shadcn UI
- **Backend**: Express (minimal, serving static assets)
- **Styling**: Dark mode (#0f0f0f), Space Grotesk + Inter fonts, cyan/purple gradient accents

## Features
1. **Hero Section**: Massive "JAI" headline with tagline, animated gradient background
2. **Interactive Buttons**: 8 Grok-style pill-shaped buttons with cyan glow effects and hover animations
3. **Feature Cards**: 3 columns showcasing Reasoning, Real-time Knowledge, and No Filter Honesty
4. **Mobile Mockups**: Side-by-side iPhone and Android device mockups displaying JAI app
5. **Footer**: Links (About, Careers, Privacy, Terms) and social icons (Twitter/X, GitHub)
6. **Animations**: Gradient shifts, glow pulses, float-up effects, smooth transitions

## Design System
- **Colors**: Dark background (#0f0f0f), cyan primary (#00d4ff), purple accents (#a855f7)
- **Typography**: Space Grotesk for headlines, Inter for body text
- **Spacing**: Consistent padding using Tailwind's spacing scale
- **Components**: Shadcn UI Button, Card components with custom styling

## File Structure
- `client/src/pages/home.tsx`: Main landing page component
- `client/src/index.css`: Global styles with custom animations
- `client/index.html`: SEO meta tags, font imports
- `design_guidelines.md`: Comprehensive design specifications
- `attached_assets/generated_images/`: Phone mockup images

## Running the Project
```bash
npm run dev
```
Starts Express server for backend and Vite server for frontend on the same port.
